# 🤪 JokeyBlogey

**Very serious answers to extremely unserious questions.**

JokeyBlogey is a reusable GitHub Pages/Jekyll site for publishing bizarre made-up questions and their “canonical answers.”

### Included

- Colorful responsive homepage
- Individual static joke URLs
- Search/filter box
- Random Joke buttons
- SEO-friendly titles, descriptions, canonicals and structured data
- Automatic `sitemap.xml`
- `robots.txt`
- About page
- Custom 404 page
- Six starter jokes
- A reusable new-joke template

### Add another joke

Create one Markdown file inside `_jokes`.

See `NEW_JOKE_TEMPLATE.md`.
